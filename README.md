# Excel-Product-Data-Analysis
The objective of this project is to process and analyze a product inventory dataset containing details such as Product IDs, prices, quantities, and categories. Using Microsoft Excel, standard financial and statistical formulas like SUM, AVERAGE, MIN, MAX, and COUNTA were applied to aggregate overall sales metrics and evaluate total inventory records. Conditional functions such as IF, SUMIF, and COUNTIF were implemented to dynamically categorize products by price tier, sum revenues for specific categories like Electronics, and count items priced below key thresholds. Additionally, text manipulation functions including LEFT, MID, and RIGHT were utilized to extract distinct date and regional dimensions directly from structured Product ID strings.
