# Excel Product Data Analysis

## Project Overview

This project demonstrates basic **data analysis using Microsoft Excel** on a product dataset. The dataset contains information about products, brands, prices, quantities, categories, and Product IDs.

The project was created to practice fundamental Excel functions, including **mathematical, logical, conditional, and text functions**, and to understand how they can be used to analyze and transform data.

## Dataset

The Excel worksheet contains **35 product records** with the following columns:

| Column       | Description                                        |
| ------------ | -------------------------------------------------- |
| Product ID   | Identifier containing date and country information |
| Product Name | Name of the product                                |
| Brand Name   | Brand associated with the product                  |
| Price ($)    | Price of the product in US dollars                 |
| Quantity     | Number of units                                    |
| Category     | Product category                                   |


## Excel Functions Used

The following Excel functions were used during the analysis:

### Mathematical and Statistical Functions

* **SUM** – To calculate the total of numerical values.
* **AVERAGE** – To calculate the average value.
* **MIN** – To find the smallest value.
* **MAX** – To find the largest value.

### Counting Functions

* **COUNTA** – To count non-empty cells.
* **COUNTIF** – To count cells that meet a specified condition.
* **SUMIF** – To calculate the sum of values based on a specified condition.

### Logical Function

* **IF** – To perform a logical test and return a result based on whether the condition is TRUE or FALSE.

### Text Functions

* **LEFT** – To extract characters from the beginning (left side) of a text string.
* **RIGHT** – To extract characters from the end (right side) of a text string.
* **MID** – To extract characters from a specific position within a text string.

These text functions were applied to the **Product ID** to extract specific parts of the ID.
